## 约定

- 评审使用中文（与 docs 体系一致）
- 每个发现带「证据（file:line）+ 影响 + 性质」，可复核、可追责
- 评审不与文档脱节：评审更新后，同步更新 `planning/todo.md` / `development-log/`（见 postmortem 001 教训）
