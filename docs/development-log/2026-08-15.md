**踩坑记录（沉淀给后续）**：
- **lint `LocalContextGetResourceValueCall`（Error 级）**：Composable 内 `context.getString()` 会被判错，须用 `stringResource` 捕获后闭包引用；`LocalContext.current.resources` 是 Warning 级（`LocalContextResourcesRead`），最终方案是把 EXIF 提取做成纯函数（返回资源 ID 引用），彻底不依赖 Context/Resources
- **`LocalContext.current` 不能在 `LaunchedEffect`/`withContext` 内读取**（Composable 调用约束）——先试过移入协程，编译报错后回退
- **ktfmtFormat 失败 = 语法错误**：一次编辑残留了多余 `}`（原函数收尾括号），ktfmt 解析直接挂；编辑大段替换时注意 old_string 是否吃掉了函数收尾
- **detekt `EmptyFunctionBlock`**：Preview 假 Host 的空 override 需 `@Suppress` + 注释
- **并行 edit 同文件会 EIO（Win32 1175）**：同一消息内对同一文件多个 edit 偶发文件锁冲突，拆成串行或重试即可
